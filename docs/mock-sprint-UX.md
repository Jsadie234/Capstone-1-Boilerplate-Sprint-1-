The UX design includes the styled login page and Team 51 team page based on the BA requirements.

### Team Page
- Team name

- Full name
- Role
- Short blurb

### Edge Cases
- Default avatar for members without a profile photo
- Variable-length blurbs
- Long blurbs can be expanded using "Read more"
- Account dropdown with "Log out"
